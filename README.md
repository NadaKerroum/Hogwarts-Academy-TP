Ce projet est un TP de TypeScript réalisé dans le cadre de ma formation d'ingénieure à l'EHEIM. Il simule une académie de sorciers (Hogwarts Academy) pour mettre en pratique les génériques, les utility types (`Omit`, `Extract`, `Record`), les types à accès indexé, les type guards et les décorateurs de méthodes. J'y ai ajouté six fonctionnalités : l'enregistrement d'un sorcier avec attribution automatique de l'identifiant, le filtrage des sorciers par maison, la gestion des événements de lancement de sorts, la validation de la puissance d'un sort, la mise en cache des résultats d'une méthode et un contrôle strict des maisons autorisées. Chaque exercice est testé dans `src/main.ts` et s'exécute avec `npm start`.
